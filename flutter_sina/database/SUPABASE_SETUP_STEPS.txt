SUPABASE SETUP STEPS

1) داخل Supabase یک پروژه بساز.
2) از Project Settings > API این دو مقدار را بردار:
   - Project URL
   - anon public key

3) فایل SQL زیر را در Supabase SQL Editor اجرا کن:
   database/full_app_schema.sql

4) پروژه Flutter را با این دستور اجرا کن:

flutter run -d chrome --dart-define=SUPABASE_URL="YOUR_PROJECT_URL" --dart-define=SUPABASE_ANON_KEY="YOUR_ANON_KEY"

5) اگر اینترنت قطع باشد:
   - داده از cache خوانده می‌شود
   - تغییرات در SyncQueue ذخیره می‌شود

6) وقتی اینترنت وصل شود:
   - SyncQueue خودکار به Supabase ارسال می‌شود
